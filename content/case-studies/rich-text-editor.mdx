-  command dispatch

  => 1. DOM events on the content editor => like from the user interaction on DOM like typing , deleting. These DOM evets on contentEditable DOM element are mapped to recognized commands.
  2. Programmatically via the toolbar => User interacts with the toolbar buttons (bold, italic, underline, etc.) or within the transformer/listener

- editor receives command , make clone of the current content state ( pending state ). Apply the command effects to the cloned content state. Require both the current and previous editor state for the reconcillation

- the reconciler recives both the current and previous editor changes and compares the two to create/update/remove the relavant DOM node corresponding to the new editor state.


### Listerner
 => mechanism for allow the developer when an certain operation has occured. dev can add event listener and act occordingly
### Transformer
  => mechanism to respond to change within the editor before reconcillation happens
